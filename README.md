# GRC Compliance Audit Lab

## Overview

This project demonstrates a simulated Governance, Risk, and Compliance
(GRC) cybersecurity assessment for a fictional healthcare organization,
River Valley Medical Services (RVMS).

The project evaluates organizational cybersecurity risks and documents
recommended security controls using the NIST Cybersecurity Framework
(CSF) 2.0 as a reference.

## Objectives

- Identify critical organizational assets
- Identify cybersecurity threats and vulnerabilities
- Perform qualitative risk scoring
- Create a cybersecurity risk register
- Perform a NIST CSF 2.0 gap assessment
- Recommend security controls
- Develop organizational security policies
- Communicate cybersecurity risks to management

## Risk Methodology

Risks were evaluated using:

Risk Score = Likelihood × Impact

Likelihood and impact were rated from 1 to 5.

Risk levels:

- 1-4: Low
- 5-9: Medium
- 10-16: High
- 17-25: Critical

## NIST CSF Functions Evaluated

The assessment considers the six NIST CSF 2.0 functions:

- Govern
- Identify
- Protect
- Detect
- Respond
- Recover
