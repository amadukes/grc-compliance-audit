# Password Policy

## Purpose
This policy establishes password requirements for RVMS accounts and systems.

## Requirements

- Users must create strong passwords or passphrases.
- Passwords must not be shared with other users.
- Default passwords must be changed before systems are placed into service.
- The same password should not be reused across company and personal accounts.
- Multi-factor authentication must be used when available.
- Suspected compromised passwords must be changed immediately.
- Passwords should be stored using an approved password manager when needed.

## Account Protection

Repeated unsuccessful login attempts should trigger appropriate account
protection controls and security monitoring.
